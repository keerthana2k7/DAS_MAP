# DevTrack — DSA & Full Stack Roadmap Tracker
> *"Learn. Track. Revise. Build."*

A modern, developer-centric learning platform and progress tracker built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

---

## 🚀 Key Features

- **344 Roadmap Topics Ingested**: Complete coverage across 9 core engineering domains (DSA, Web/API, Security, Developer Tools, DevOps, Software Engineering, System Design, AI for Developers, and 4 Full-Stack Projects).
- **Interactive Progress Dashboard**: Dynamic metric calculations (0% initial state), real-time category ratios, and live goals.
- **Spaced Repetition Revision System**: Scientific intervals (`1d → 3d → 7d → 14d → 30d`) with urgency badges (`Overdue`, `Due Today`, `Upcoming`).
- **Live Study Session Tracker**: Floating timer widget with Start, Pause, Resume, Stop, and Reset controls + reflections logging.
- **DSA Practice Problem Tracker**: Problem logs with difficulty tiers (Easy, Medium, Hard) and platform tags (LeetCode, GFG, Codeforces, HackerRank).
- **GitHub-style Study Streak Heatmap**: 84-day activity calendar displaying heat levels and streak statistics.
- **Project Development Dashboards**: Dedicated trackers for 4 progressive projects with architecture checklists and tech badges.
- **Data Persistence**: Offline-first `LocalStorage` synchronization with complete JSON Export & Import capabilities.
- **Theme Support**: Dark charcoal developer aesthetic with Light Mode toggle.

---

## 🛠 Tech Stack

- **Frontend**: React 18 / 19, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Charts**: Recharts
- **Routing**: React Router

## 💻 Getting Started

### Prerequisites

- Node.js (v20+ recommended)
- npm or yarn

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/keerthana2k7/DAS_MAP.git
   cd DAS_MAP
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Production Build

```bash
npm run build
```
